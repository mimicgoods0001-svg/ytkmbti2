PRD: MBTI 性格测试 Landing Page (H5 极简版)
1. 项目背景与目标
目标：在 X (Twitter) 上病毒式传播，通过有趣的 16 人格测试吸引用户。

核心动作：用户完成测试后，展示性格结果，并强引导点击跳转到 Yoitoki 的 Web 端或 App 下载页。

设计风格：极简、高饱和度或插画风（适合移动端社交媒体预览）。

2. 技术栈建议 (AI 选型)
框架：Next.js 或 React (Vite)

样式：Tailwind CSS (用于快速实现响应式 UI)

动画：Framer Motion (增加交互的高级感)

部署：Vercel 或 Netlify (方便生成 X 预览链接)

3. 页面结构与流程
3.1 欢迎页 (Hero Section)
标题：MBTI测试，寻找你的灵魂颜色

副标题：3分钟发现真实的你，准的让人毛骨悚然！

行动按钮：[立即开始测试]

3.2 测试交互页 (Quiz Interface)
题目逻辑：25题，每题2个选项

交互形式：单选题。点击选项自动翻页，上方带有进度条。

逻辑算法：按照经典的 E/I, S/N, T/F, J/P 四个维度计分

3.3 结果展示页 (Result Page)
性格标题：例如：竞选者 ENFP

性格画像：简短的描述文字。

关键标签：例如：自由灵魂、创意、社交达人

转化引导 (核心)：

文案：[例如：在 Yoitoki 寻找与你 100% 匹配的灵魂伙伴]

跳转链接：[在此填写 Yoitoki 的 URL]

下载按钮：[立即下载 Yoitoki]
